Ochrana osobních údajů & cookies

Naposledy aktualizováno: listopad 2026

Kdo je provozovatelem

Web KryptoProfík provozuje Ace321cz (kontakt: ace321cz@gmail.com). Web je nezávislý vzdělávací projekt, nejedná se o registrovaného poskytovatele finančních ani daňových služeb.

Jaká data se sbírají

Web nepoužívá registraci ani uživatelské účty — nic si od vás nevyžaduje. Po odsouhlasení cookie lišty se spouští Google Analytics 4, který anonymizovaně sbírá: navštívené stránky, přibližnou polohu (zemi/město), typ zařízení a prohlížeče, a jak dlouho na webu zůstáváte. IP adresa se při tom anonymizuje. Tato data neslouží k vaší identifikaci jako konkrétní osoby.

Cookies

Web používá cookies pouze pro statistiku návštěvnosti (Google Analytics) a pro zapamatování vašich voleb (jazyk, světlý/tmavý režim, postup v kvízu). Žádné cookies pro reklamu ani sledování napříč jinými weby. Souhlas s analytickými cookies můžete kdykoliv změnit vymazáním dat prohlížeče pro tento web — lišta se pak zobrazí znovu.

Externí služby

  • Google Analytics (Google Ireland Ltd.) — anonymní statistika návštěvnosti
  • Google Fonts — načítání písma Inter a JetBrains Mono
  • Font Awesome (cdnjs) — ikony
  • TradingView — živý graf kurzů kryptoměn (widget třetí strany)
  • CoinGecko API — aktuální ceny kryptoměn

Tyto služby mohou při načtení stránky zaznamenat vaši IP adresu — řídí se vlastními zásadami ochrany soukromí daných poskytovatelů.

Vaše práva

Protože web neukládá žádné osobní účty ani databázi s vašimi osobními údaji, nemáme co mazat ani exportovat na vyžádání — veškerá analytická data jsou anonymní a agregovaná. Pokud byste přesto měli dotaz ohledně zpracování dat, napište na ace321cz@gmail.com.

Není to finanční ani daňové poradenství

Obsah webu je vzdělávací a zjednodušený. Nejedná se o investiční, finanční ani daňové poradenství — před reálným rozhodnutím se vždy poraďte s kvalifikovaným odborníkem.
